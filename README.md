My work bridges low-level browser fundamentals—crafted with **JavaScript, C/C++, HTML5, and CSS3**—with modern production frameworks including **React 19**, **Next.js 16 (App Router)**, and **Three.js / React Three Fiber**. ## Featured Works

### 1. Web & Engineering
* **[Completely Normal Notepad](https://github.com/Dr-Ghost7/completely-normal-notepad)** — [Live Demo](https://completely-normal-notepad-beige.vercel.app) — A client-side text editor where deleted writing materializes into floating interactive kinetic entities that can be caught, bottled, or restored, featuring procedural Web Audio sound synthesis.
* **[Neural Network X-Ray](https://github.com/Dr-Ghost7/neural-network-xray)** — [Live Demo](https://neural-network-xray-98rk-tau.vercel.app) — An interactive 3D WebGL visualizer and ablation sandbox for real-time MNIST neural network inference running directly in the browser with sub-millisecond forward passes.
* **[A* vs. Q-Learning Simulation](https://github.com/Dr-Ghost7/astar-vs-qlearning-simulation)** — An algorithmic benchmark comparing classical deterministic heuristic search ($A^*$) against a reinforcement learning agent (Q-Learning) across 250 procedurally generated mazes with an 84.8% convergence rate.
* **[Flag Memory](https://github.com/Dr-Ghost7/flag-memory-app)** — An interactive cognitive recall application featuring a 3-tier Leitner Box spaced repetition system (Academy mode), high-stakes Death Mode with progressive difficulty scaling and timer penalties, Inversion mode, and audio-visual feedback.

Analyzes key hold duration (dwell time), flight time between taps, touch pressure, contact area, and center accuracy using an explainable classifier and a live real-time oscilloscope.

## Getting Started Locally

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Dr-Ghost7/web-portfolio.git
   cd web-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
